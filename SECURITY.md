# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of WinSecure seriously. If you discover a security vulnerability or sensitive information exposure:

1. **Do NOT file a public issue.**
2. Please privately report security vulnerabilities directly to the maintainer via GitHub Security Advisories or via email.
3. Include detailed steps to reproduce the issue, proof of concept, and environment details.
4. We aim to acknowledge receipt of security reports within 48 hours and provide a coordinated resolution timeline.

Thank you for helping keep WinSecure and the community safe.
